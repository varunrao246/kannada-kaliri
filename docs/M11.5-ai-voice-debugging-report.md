## 1. ROOT CAUSE INVESTIGATIONS

### 1.1 Root Cause of Gnani Prisma STT Failure (`HTTP 400: UNSUPPORTED_AUDIO_FORMAT`)
- **Investigation:**
  Gnani Prisma STT endpoint (`https://api.vachana.ai/stt/v3`) accepts exclusively: `flac, mp3, m4a, wav, ogg, aac`.
  However, browser `MediaRecorder` in Chromium-based browsers (Chrome, Edge, Brave) records audio by default in `audio/webm;codecs=opus`.
  The original client recorder sent `spoken_kannada.webm` to the backend, which forwarded the WebM container directly to Gnani.
  Gnani inspected the file extension/container and rejected it with HTTP 400: `UNSUPPORTED_AUDIO_FORMAT`.
- **Diagnostic Finding:**
  Gnani's single API key (`GNANI_API_KEY`) was 100% valid for both STT and TTS. When provided with an authentic 16-bit Linear PCM WAV file (`RIFF....WAVE`), Gnani Prisma STT returned HTTP 200 and recognized the spoken Kannada phrase in under 0.25 seconds.

### 1.2 Root Cause of AI Kannada Guru Credentials Warning (`AI Runtime Credentials Required`)
- **Investigation:**
  In `.env.local`, only Supabase keys and `GNANI_API_KEY` were defined. Neither `AI_API_KEY` nor `GEMINI_API_KEY` was present.
  Additionally, the previous configuration loader:
  1. Failed to detect documentation placeholder values (e.g. `your_gemini_api_key_here`). If a user copied the example verbatim, it was treated as a real key, causing an obscure 400/401 API failure later.
  2. Failed to distinguish missing keys vs placeholder keys vs invalid keys in the UI.

1. **No Sensitive Leakage:**
   - Neither `.env.local` nor any live API keys were logged, printed, or exposed to the client bundle.
2. **Audio Ephemerality:**
   - Audio recordings in `/api/speech/transcribe` remain buffered in memory only during transcription and are immediately garbage-collected. No voice media or transcripts are written to persistent disk.

   - Both `startAudioRecording` and `VoicePractice` explicitly invoke `stream.getTracks().forEach(t => t.stop())` upon stopping or canceling, ensuring the microphone hardware indicator immediately shuts off.
